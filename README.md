# 🌐 Makkena Venkata Ramana — Developer Portfolio

- 🧑‍💻 About Me, Skills, Work History, Education, Projects, and Contact sections
- 🌗 Light/Dark theme toggle
- 📄 Resume download (PDF)

- 🔍 SEO meta tags and social share support
